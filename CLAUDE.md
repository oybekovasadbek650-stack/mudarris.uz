# O'rinbosar tizimi — frontend + backend + bot

Maktab/o'quv markazi uchun o'rinbosar o'qituvchi topish tizimi.
Bu repo: frontend (ildiz, Mini App + Rahbariyat paneli) va `server/` (backend + Telegram bot). Loyiha to'liq foydalanuvchiniki (Amirhon 2026-11-21 da topshirgan).
Backend tafsilotlari: `server/README.md`. Talablar manbai: `server/data/orinbosar_test_jadvali.xlsx` (Excel: qoidalar, jadval, 19 test ssenariysi).
Foydalanuvchi o'zbek tilida yozadi — javoblar, UI matnlari va hujjatlar o'zbekcha.

## Ishga tushirish
```
npm install
npm run dev      # http://localhost:5173  (/app — Mini App, /admin — panel)
npm run build
npm run lint
```
Haqiqiy backend bilan: `.env.local` -> `VITE_USE_MOCK=false`, keyin `cd server && npm run dev` (port 8787; Vite `/api` ni proxy qiladi).
⚠️ Yo'lda `R&D` bor — `.bin` shimlar Windows'da buziladi, shuning uchun package.json skriptlari `node node_modules/...` orqali chaqiriladi. Shunday qoldiring.

## Stek
React 19 + TypeScript + Vite 8, Tailwind CSS v4 (`@tailwindcss/vite`), React Router 7, TanStack Query 5, lucide-react (ikonkalar), Manrope shrifti (Google Fonts, index.html).
Telegram: `telegram-web-app.js` skripti index.html da; o'ram — `src/lib/telegram.ts`. Deploy: Vercel (`vercel.json` SPA rewrite).
